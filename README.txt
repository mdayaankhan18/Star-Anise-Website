The website is a static HTML/CSS site and can be hosted free on GitHub Pages or Cloudflare Pages.

The menu content and prices were taken from the supplied September 2026 Colaba menu.
The site includes WhatsApp, Instagram and Google Maps buttons.

To publish on GitHub Pages:
1. Create a free GitHub account at github.com.
2. Create a new public repository, e.g. star-anise-website.
3. Upload index.html and the assets folder.
4. Repository Settings → Pages → deploy from the main branch.
5. GitHub will provide the free website address.

Before launch, replace/add product photography, confirm current opening hours, and connect a custom domain if desired.
